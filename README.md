# Image Base64 Tool

Одностраничный PHP-сайт для преобразования изображений в Base64 и обратно.

## Возможности

- Загрузка изображения через форму.
- Кодирование содержимого файла через `base64_encode()`.
- Вывод Base64-текста.
- Копирование результата в буфер обмена.
- Обратное преобразование Base64 в изображение.
- Поддержка обычной Base64-строки и `data:image/...;base64,...`.
- Проверка, что загруженные и декодированные данные действительно являются изображением.
- Ограничение размера изображения до 10 МБ.

## Запуск локально

```bash
php -S localhost:8000
```

После запуска открой:

```text
http://localhost:8000
```

## Требования

PHP 8+
