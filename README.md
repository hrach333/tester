# Image Base64 Tool

Одностраничный сайт для преобразования изображений в Base64 и обратно.

Сайт полностью работает в браузере на JavaScript. Изображения не отправляются на сервер.

## Возможности

- Картинка → Base64.
- Base64 → картинка.
- Поддержка обычной Base64-строки и `data:image/...;base64,...`.
- Предпросмотр декодированного изображения.
- Копирование чистого Base64.
- Копирование полного Data URL.
- Проверка формата и размера изображения.
- Ограничение размера до 10 МБ.
- Подходит для GitHub Pages.

## GitHub Pages

В настройках репозитория открой `Settings → Pages`.

В `Build and deployment` выбери:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

После сохранения GitHub опубликует сайт по адресу:

`https://hrach333.github.io/tester/`

## Локальный запуск

Можно просто открыть `index.html` в браузере. PHP и сервер не нужны.
